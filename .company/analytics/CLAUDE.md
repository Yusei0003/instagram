# 分析部

投稿の結果を記録して、次に活かす。

## 担当
- 数字は投稿の 3 日後・7 日後に `tools/insights.mjs` が `metrics.csv` へ自動で記録する（オーナーが手で貼ったら追記する）
- 月に 1 回、`reports/YYYY-MM.md` に振り返りを書く

## 記録する数字（Instagram API のインサイト。取れない指標は空欄）
リーチ、いいね、コメント、保存、シェア、プロフィールアクセス、フォロー

## 振り返りの観点
- 保存数が多い投稿の共通点（テーマ、1 枚目の問いかけ、枚数）
- 伸びなかった投稿の仮説と、次に試すこと
- 改善案は企画部・編集部・デザイン部への具体的な提案にする
